**under cover** — эксперимент: что получится, если поручить нейросетям почти весь альбом — от музыки до обложек. Модели генерировали звук, разбирали готовые треки, предлагали названия и рисовали картинки. Я задал стиль и желаемый результат, а потом отбирал подходящее и вносил небольшие правки.

Получилось двенадцать инструментальных треков на 31 минуту 45 секунд: мягкий бас, ровный пульс, синтезаторы и короткие вокальные фрагменты без слов. Хотелось посмотреть, соберётся ли из отдельных генераций что-то цельное.

**«One-shot»** — название оптимистичное. Между генерациями всё-таки приходилось выбирать, уточнять и иногда просить ещё вариант. По ходу стало понятно, что отбор здесь и есть основная работа.

<h2 id="kusaku-brand">kusaku / クサク</h2>

**kusaku** — мой ник и имя, под которым я выпускаю музыку. Логотип тоже появился в ходе эксперимента: я описал, чего хочу, модели предложили варианты, я выбрал подходящие. В знаке остались плотная латиница, катакана и разделительная линия.

Мне понравилось написание **クサク**, но и латинское **kusaku** хотелось оставить. Так у одного имени появились два написания и две компоновки — вертикальная и горизонтальная. Цвета взяты из палитры обложек.

Оказалось, в японском есть слово [句作 — くさく, kusaku](https://kotobank.jp/word/%E5%8F%A5%E4%BD%9C-483054): сочинение хайку и рэнку, связанных стихотворных цепочек. Для альбома без слов получилось неожиданно литературно. В самом логотипе используется **クサク** — катакана, передающая звучание имени.

Обложки я просил делать дерзкими и запоминающимися: необычные образы, выразительные композиции, свой характер у каждого трека. В серию их собирают свет, ткань, стекло и повторяющийся знак. Логотип добавлялся отдельно, чтобы сохранять форму букв, а цвет подбирался к каждому кадру.

## Что делали нейросети, а что — я

Основа запроса — **инструментальный deep house / indie electropop, 123 BPM, без текста**. Короткие женские вокальные нарезки, дыхание и отдельные слоги должны были работать как ритмические акценты. Глитчи и заикания — как редкие детали поверх тёплого баса и синтезаторов.

На общей обложке это вполне буквальная ткань, за которой стоят два человека. В остальных сценах — близость, паузы и то, что остаётся недосказанным.

## Что получилось

Отдельные генерации удалось собрать в альбом с общим настроением. Музыка, названия и картинки делались на разных этапах, а вместе удержались за счёт отбора. В этом для меня и был интерес эксперимента: передать моделям генерацию и посмотреть, сколько всё ещё зависит от решения «это оставляем».

Сегодня, в ноябре 2026 года, всё это выглядит довольно неплохо. Недостатков хватает, но тем интереснее, что будет дальше. Обещаю возвращаться сюда из будущего и сравнивать: что изменилось в генерации и что — в моём отношении к результату. Будущий я, ты обещал.

В конце стоят *stay a while* и *five more minutes* — две просьбы задержаться. Для альбома это подходящее завершение. Хотя по смыслу он всё ещё пытается выпросить продолжение.

### Об описаниях и цифрах

Модели разбирали полные записи и короткие фрагменты, иногда приходя к разным выводам. Жанровые определения и сравнения тембров стоит читать как интерпретации. По ним нельзя установить конкретное оборудование или происхождение каждого звука.

Длительности взяты из исходных WAV, BPM и тональности — из рабочих данных, по которым согласовывался порядок. Отдельно для статьи они не измерялись. 123 BPM в базовом запросе — желаемый темп; цифры в карточках относятся к рабочему референсу. Обложки и варианты логотипа тоже сгенерированы; сцены на изображениях вымышлены.

(() => {
  const article = document.getElementById('under-cover');
  const lightbox = document.getElementById('under-cover-lightbox');
  const image = lightbox.querySelector('img');
  const caption = lightbox.querySelector('figcaption');

  article.addEventListener('click', (event) => {
    if (event.defaultPrevented || event.button !== 0
      || event.metaKey || event.ctrlKey || event.shiftKey || event.altKey) return;
    const link = event.target.closest('a');
    if (!link) return;

    if (link.hasAttribute('data-album-art') && lightbox.showModal) {
      event.preventDefault();
      image.src = link.href;
      image.alt = link.querySelector('img').alt;
      caption.textContent = image.alt;
      lightbox.showModal();
    } else if (link.dataset.albumTrack) {
      const button = [...document.querySelectorAll('#soundcloud-tracks .soundcloud-track')]
        .find((item) => item.querySelector('.soundcloud-track-title').textContent.trim() === link.dataset.albumTrack);
      if (button) {
        event.preventDefault();
        button.click();
      }
    }
  });

  lightbox.addEventListener('click', (event) => {
    if (event.target === lightbox) lightbox.close();
  });
  lightbox.addEventListener('close', () => image.removeAttribute('src'));
  document.addEventListener('turbo:before-cache', () => lightbox.close(), { once: true });
})();
</script>
