# SK Berlin photographs

Photographer: **Silvio Schwartz**, [berlin_sk68 on Flickr](https://www.flickr.com/photos/25054024@N00/).

All 71 JPEG photographs in this directory are licensed under
[Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/).
The licence was checked against the public Flickr metadata for each photograph
on 2026-11-03 (Flickr licence ID 12).

These are Flickr's 1024-pixel JPEG renditions. Resolution and file size differ
from the originals; the full composition and native proportions are preserved.
Adapted photographs remain under CC BY-SA 4.0. No ownership of these photographs
is claimed by the blog author.

Individual source URLs, photographer credit, dimensions and licence links are
recorded directly in `_posts/2026-11-03-berlin-sk68-shkoly-bliznetsy.md`,
with source and licence links beside each photograph. The numeric suffix of each JPEG filename is its Flickr photo ID:
`https://www.flickr.com/photos/25054024@N00/PHOTO_ID/`.

Locations and historical names are based on Silvio Schwartz's
[SK68 Berlin catalogue](https://www.sk68-berlin.de/gebaeude/), accessed 2026-11-03.
Additional verification sources are linked in the article’s address catalogue. The catalogue's text has not been reproduced as article prose.
